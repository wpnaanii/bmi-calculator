# BMI Calculator

This is a BMI Calculator web application built with Node.js and Express.

## Features
- BMI calculation
- BMI category detection
- Fat index and muscle index calculation
- Health recommendations
- Styled UI with CSS

## Technologies
- Node.js
- Express
- HTML
- CSS

## How to run
1. Install dependencies:
   npm install
2. Run the server:
   node app.js
3. Open in browser:
   http://localhost:3000
